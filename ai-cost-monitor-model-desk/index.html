DATA & METHODOLOGY — This dashboard is a curated snapshot, not a live feed: no provider publishes a unified pricing API, so every public tracker (including this one) is assembled by hand or scraped from pricing pages. To keep this current yourself: (1) re-run this research monthly and edit the MODELS array at the top of this file's script — it's plain JSON, built to be extended; (2) for automated tracking, point a scheduled job at community-maintained feeds such as openrouter.ai/models (has a models API), the DeepSeek/OpenAI/Anthropic/Google pricing pages directly, or aggregators like aipricing.guru and pricepertoken.com which publish raw JSON; (3) for usage/spend rather than list price, pull actuals from your own provider console or billing export (Anthropic Console usage API, OpenAI usage API, Google Cloud Billing export) rather than list prices, since caching/batching/regional multipliers change effective cost substantially. All figures here are list API rates as published or reported in trade press as of early July 2026; verify against the provider's own pricing page before budgeting.
